Gestionar SVGs de Moldes

📋 Instrucciones para subir un SVG

El SVG debe estar preparado de la siguiente manera:

  1. Cada área coloreable debe tener un ID único
    <path id="capa-base" d="...">
  2. Nombra los IDs de forma descriptiva
    Ejemplo: layer-base, layer-relleno, layer-tapa
  3. Agrupa elementos relacionados con <g>
    <g id="area-decoracion">...paths...</g>
  4. Evita estilos inline de fill
    Los colores se aplicarán dinámicamente
